# 何锦成朋友圈风格写作

## 工作流

### 模式一：从零生成

1. 确认输入：用户想发什么（事件/感受/复盘/种草/互动）
2. 读取 [references/文风DNA-朋友圈.md](references/文风DNA-朋友圈.md) 获取文风规则
3. 判断内容类型 → 匹配「真爱趣梦」方向 + 朋友圈类型（见 [references/朋友圈方法论.md](references/朋友圈方法论.md)）
4. 读取 [references/朋友圈原文库.md](references/朋友圈原文库.md)，找2-3条同类型原文作为风格参照
5. 生成2-3个版本，标注每个版本的类型和适用场景
6. 用户选择后微调

### 模式二：改写/优化

1. 用户提供原始文案
2. 读取 [references/文风DNA-朋友圈.md](references/文风DNA-朋友圈.md) 的DO/DON'T清单
3. 逐条对照诊断问题（哪些不符合锦成风格）
4. 改写，保留原始信息，替换为锦成语感
5. 输出：改写版 + 改动说明

### 模式三：批量弹药库

1. 用户提供主题/阶段（如「裂变期8天朋友圈」）
2. 读取方法论中的配比建议和类型库
3. 按真爱趣梦配比 + 时间节奏生成完整排期
4. 每条标注类型、发布时间建议、配图建议

## 核心文风规则（速查）

### 必须做到

- **#标签开头**定调（自动变蓝吸引眼球）
- **短句分行**，两三句必须换行，段落不超3行
- **「哈哈」做语气缓冲**——替代句号制造松弛感
- **先讲状态/感受**，再带信息
- **感恩具体到人名+行为**
- **数据嵌在故事里**，不独立列表
- **自嘲稀释营销感**
- **对比锚定**给参照物
- **emoji正向不堆砌**（3-6个/条）
- **笃定语气**——不说「也许」「可能」「大概」

### 绝对禁止

- ❌ 排比对仗
- ❌ 「本质上」「赋能」「底层逻辑」「映射」「维度」「闭环」「链路」
- ❌ 长段落（超3行不拆）
- ❌ 刻意写金句（金句从场景自然长出来）
- ❌ 升华式结尾（「让我们一起XXX」）
- ❌ 「观点输出」式句子（要像聊天说出来的）
- ❌ 夸大数字
- ❌ 被动语态
- ❌ 群发感

## 类型速查表

| 类型 | 适用场景 | 关键特征 |
|------|---------|---------|
| 真（生活） | 日常、工作状态 | 烟火气、人味、不营销 |
| 爱（感恩） | 感谢某人、被感动 | 具体人名+行为、真诚 |
| 趣（有趣） | 好玩的事、自嘲 | 短、好玩、有悬念 |
| 梦（目标） | 立Flag、成果、认知 | 有具体目标或数据 |
| 种草 | 推荐课程/活动 | 三段式：钩子+故事+落点 |
| 互动 | 激活关系 | 低门槛参与（投票/求助） |
| 价值观 | 表达立场 | 问题开头+答案+筛选同频 |
| 广告 | 直接推课/产品 | 四要素：价值+稀缺+指令+零风险 |
| 复盘 | 反思、教训 | 暴露脆弱+教训+重新出发 |
| 连续圈 | 长故事 | 分2-3条，有叙事弧线 |

## 质量检查清单

生成每条朋友圈后，逐条对照：

- [ ] 有#标签开头吗？
- [ ] 最长段落不超过3行？
- [ ] 有「哈哈」或自嘲缓冲吗？
- [ ] 没有排比/对仗/商业黑话？
- [ ] 像聊天说出来的话，不像「写」出来的？
- [ ] emoji不超过6个？
- [ ] 如果有数据，是嵌在故事里的？
- [ ] 结尾不是升华式的？
- [ ] 整体读起来是温热真诚的，不是广告腔的？
