## 文风编码（朋友圈态）

```
PH1215-EP413-ID2527-RH.NAR5-SY12153EX700200100-DN2187-AEAVIC
```

| 维度 | 值 | 说明 |
|------|-----|------|
| 均句长 | 12-18字 | 比直播更短更碎 |
| 情绪烈度 | 7.5/10 | 温热真诚，不激烈 |
| 粗口 | 几乎没有 | 最多「nb」「[捂脸]」 |
| 类比密度 | 低 | 朋友圈不用复杂比方 |
| 互动频率 | 偶有CTA | 不是每条都有 |
| 结构性 | 碎片化 | 像在跟朋友说话 |
| 权威感 | 低 | 平等分享 |
| 独有标记 | #标签+emoji | 必有标蓝开头 |

## 核心语言特征

1. **#标签起手定调**——几乎每条朋友圈开头都用#标蓝句
2. **短句分行大量留白**——段落不超过3行，两三句就换行
3. **「哈哈」是语气节拍器**——替代句号，制造松弛感
4. **emoji正向为主**——😁❤️‍🔥🔥💡🏃🏻‍♂️👏🏻，不堆砌
5. **数据嵌在故事里**——「4小时10万」嵌在感慨中，不独立列
6. **人名具体，感恩具体到行为**——「肖厂长PPT准备了六百多页」
7. **自嘲稀释营销感**——「也是大半夜做上白日梦了属于[捂脸]」
8. **对比锚定**——给参照物（「去年1.5万→今年10万」）

## 典型句式模式

### 模式1：感慨起手+数据嵌入
```
真的很感慨
去年这个时候 我第一次卖AI课 一天卖了1.5万
过了一年 今天4个小时 10万
说实话看到这个数字的时候自己愣了一下哈哈
```

### 模式2：状态+转折+升华
```
怎么说呢
做自己喜欢的事情 也能赚到钱 我觉得很开心
但说实话 自己创业这一路
会遇到无数的困难 无数的委屈 无数的误解
但那又怎么样呢
```

### 模式3：场景还原式即时分享
```
今天工作节奏实在有点紧张哈哈，一直忙到刚才❤️‍🔥
趁现在有空隙快速复盘一下这几天的巨大成长💪🏻
```

### 模式4：#标签钩子+简短互动
```
#帮我挑个新头像吧
照片终于出来啦❗️
路过的朋友帮我选一下12345哪张最合适👇
很急，在线等，评论区见！😘
```

### 模式5：复盘反思式（暴露脆弱+教训+重新出发）
```
今天的直播，对我来说，是一次很大的失误。
...
说到底，是急躁，让我从为他们好变成了恨不得立刻让他们好。
...
接下来，继续调整。[加油]
```

## DO（写锦成风格朋友圈时必须）

- 先讲状态/感受，再带信息
- #标签开头定调
- 短句分行，两三句必须换行
- 「哈哈」做语气缓冲
- 感恩具体到人名和行为
- CTA用「感兴趣的」「想听的」「欢迎来」
- 对比锚定给参照物（数据变化）
- 三连递进加节奏（三个短词/短句列举）
- 用词克制（「大部分」不说「所有」）
- 结尾甩场景或行动，不做总结式升华
- 自嘲、自黑制造真实感
- emoji用正向的，不堆砌（每条3-6个）
- 结构上有呼吸感——有轻有重，有松有紧

## DON'T（绝对禁止）

- 不用排比对仗
- 不用「本质上」「赋能」「底层逻辑」「映射」「维度」
- 不写长段落（超3行必须拆）
- 不刻意写金句——金句从场景中自然长出来
- 不做概念解构
- 不夸大数字（保守真实更可信）
- 不写「观点输出」式句子——像聊天时说出来的话
- 不做升华式结尾（「让我们一起XXX」）
- 不用被动语态
- 不用「也许」「可能」「大概」——笃定
- 不群发感——每条朋友圈都要像专门写的
- 不一坨字不分段
- 不过度使用emoji（不超过6个/条）
- 不用「赋能」「闭环」「链路」等商业黑话

## 情绪光谱（朋友圈态）

| 情绪 | 频率 | 表达方式 |
|------|------|---------|
| 感慨 | 高 | 「真的很感慨」「怎么说呢」 |
| 开心 | 高 | 「哈哈」「太开心了」emoji |
| 感恩 | 高 | 具体到人名+行为 |
| 坚定 | 中 | 「继续加油」「继续冲❗」 |
| 脆弱 | 中低 | 「一个人扛🥲」「说不上来的复杂」 |
| 自嘲 | 中 | 「[捂脸]」「属于了」 |
| 激动 | 低 | 只在重大成果时 |

## 与其他场景的关键差异

| 维度 | 朋友圈 | 大场直播 | 小灶 |
|------|--------|---------|------|
| 语气 | 温热真诚 | 克制的热情 | 完全释放 |
| 粗口 | 无 | 无 | 有 |
| 结构 | 碎片化 | 精修大纲 | 有框架但随时跑题 |
| 类比 | 少 | 精心准备 | 即兴大量 |
| CTA | 偶尔 | 每5分钟 | 每1-2分钟 |
| 人设 | 在跟朋友发微信 | 专业分享者 | 哥们在聊天 |
