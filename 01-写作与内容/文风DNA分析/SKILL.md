# 文风DNA分析

对任意文本进行两层分析：量化编码（可比较、可复制）+ 哲学级深度解析（理解底层逻辑）。

---

## 第零步：判断分析模式

用户发来文本后，先判断需求：

**模式A：完整分析（默认）**
- 特征：用户说"分析文风"、"拆解文风DNA"
- 处理：同时输出编码 + 深度解析

**模式B：仅编码**
- 特征：用户说"编码"、"量化"、"对比文风"
- 处理：只输出编码部分，适合快速对比多个作者

**模式C：仅深度解析**
- 特征：用户说"深度分析"、"哲学分析"
- 处理：只输出深度解析部分

如果不确定，默认走模式A。

---

## 分析流程

### 第一步：确认文本

收到文本后，先确认：
- 文本长度是否足够（至少300字才能做有效分析）
- 如果太短，告诉用户："这段文本偏短，分析结果可能不够准确，建议提供更多同一作者的文本。"

### 第二步：量化编码

参考 [references/编码手册.md](references/编码手册.md) 中的完整编码系统。

逐层分析并编码：

① **哲学层（PH）**：统计平均句长，判断本体论类型和时间观
② **认识论（EP）**：判断知识来源、验证方式、真理观
③ **意识形态（ID）**：7个维度各打1-9分
④ **修辞层（RH）**：识别论证方式占比、修辞手法、节奏类型
⑤ **句法层（SY）**：统计句长分布、复杂度、标点风格
⑥ **领域（DN）**：判断专业度、术语占比、口语占比
⑦ **审美排斥（AE）**：识别作者显式批判的写法 + 行文中系统性缺席的手法

**输出格式：**

```
## 文风DNA编码

完整编码：PH____-EP___-ID_______-RH________-SY________________-DN________-AE___

### 逐层解读

| 维度 | 编码 | 含义 |
|------|------|------|
| 哲学层 | PH____ | [解读] |
| 认识论 | EP___ | [解读] |
| 意识形态 | ID_______ | [解读] |
| 修辞层 | RH________ | [解读] |
| 句法层 | SY________________ | [解读] |
| 领域 | DN________ | [解读] |
| 审美排斥 | AE___ | [显式批判了什么 + 隐式回避了什么] |

### 一句话总结
[用一句话概括这个文风的核心特征]
```

### 第三步：深度解析

参考 [references/深度解析框架.md](references/深度解析框架.md) 中的完整分析框架。

按5个维度递进分析：

① **本体论-认识论基础**（20%）：作者如何构建"真实"？知识从哪来？
② **语言哲学维度**（30%）：维特根斯坦双轨、符号运作、言语行为
③ **意识形态-权力分析**（25%）：福柯视角、马克思主义、隐含预设
④ **现象学-身体性**（15%）：意向性、身体感受、生活世界质感
⑤ **美学-修辞特征**（10%）：崇高/优美、陌生化、隐喻系统、节奏
⑥ **审美排斥系统**：显式批判（作者明确命名的坏写作）+ 隐式排斥（系统性缺席的手法）+ 判断依据

**输出格式：**

```
## 文风DNA深度解析

### 【核心特征】
[3-5个关键词，用 + 连接]

### 【哲学坐标】
- 本体论：
- 认识论：
- 语言观：
- 权力意识：

### 【典型句式分析】
[引用2-3句原文，逐句拆解：词汇选择 -> 句法结构 -> 哲学含义]

### 【深层结构】
- 二元对立：[核心张力]
- 症候阅读：[沉默/回避之处]
- 意识形态效应：[塑造何种主体]

### 【审美排斥】
- 显式批判：[作者明确说「这样写不行」的具体写法，引用原文]
- 隐式排斥：[行文中从不出现的手法，推断其审美边界]
- 判断依据：[他用什么标准区分好坏——直觉/功能/读者反应/自洽]

### 【风格谱系】
- 相似作家/思想家：[说明理由]
- 历史定位：

### 【矛盾点】
[文本内部的自相矛盾，这往往最能揭示深层问题]
```

---

## 铁律

1. **每个判断必须引用原文**，不能空谈
2. **避免标签化**，要说明程度和复杂性
3. **矛盾优先**，重点关注文本内部的不一致
4. **区分有意为之和无意流露**
5. **识别表层修辞与深层结构的错位**
6. 如果文本太短或风格不明显，诚实告知，不要硬凑分析
