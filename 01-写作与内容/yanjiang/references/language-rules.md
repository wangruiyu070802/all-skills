# 语感规则（逐字稿模式）

用户要求输出逐字稿时，遵循以下规则。

## 口语化铁律

- 句子 ≤ 20 字。超过就断句
- 用短句不用长句，用简单词不用书面词
- "因此"→"所以"，"然而"→"但是"，"综上所述"→ 删掉
- 允许口语语气词（"对""OK""来"），但不滥用

## 数字代替形容词

| ❌ 模糊 | ✅ 精确 |
|---------|---------|
| 收入大幅增长 | 从月入 3000 到月入 10 万 |
| 很多人参加了 | 1600 个人 |
| 花了很多钱 | 花了三四千 |
| 很厉害 | 半年做到月入百万 |
| 大部分人不会做 | 95% 的人不会做 |

## 类比翻译

每个抽象概念必须有一个类比或画面：

| 抽象概念 | 类比翻译 |
|---------|---------|
| 服务平权 | 像自来水——以前只有有钱人喝得起干净水 |
| 认知超前但能力不够 | 拿到了地图，但体力不够，怪还是会打死你 |
| 同频社交的局限 | 在游泳池里练航海 |

## 节奏标注

逐字稿中用以下符号标注：

- `⏸️`：停顿 2-3 秒（用在核心观点前）
- `⚡3/7/10`：能量等级
- `💬`：互动点（提问/让听众打字/举手）
- `🔨`：钉子句（全场最重要的句子）

## 互动设计

线上直播每 5-8 分钟插入一个互动：

| 互动类型 | 示例 |
|---------|------|
| 选择题 | "觉得自己是 A 的扣 1，B 的扣 2" |
| 打字确认 | "理解的打个'理解'" |
| 反思题 | "想一下你微信里最常联系的 5 个人，几个能帮你赚钱？" |
| 行动题 | "现在打开你的微信，数一下……" |

**注意**：互动是为了让听众参与思考，不是为了活跃气氛。"扣个 666"是最弱的互动——它不触发思考。

## 过渡句模板

模块之间必须有明确过渡：

```
"好，第一个讲完了。第二个：____"
"这是 A。接下来说 B，它和 A 的关系是____"
"刚才说的是 why。现在说 how。"
"理论讲完了。来看实操。"
```

## 逐字稿格式示范

```
⚡7 好，我们直接进入今天的主题。

💬 先问大家一个问题：你用 AI 赚到过钱吗？赚过的扣 1，没有的扣 2。

⚡7 我猜大部分人扣的是 2。没关系。

⚡7 我去了生财有术的线下大会，1600 个人，我发现一件反直觉的事——

⏸️

⚡10 🔨 赚到钱的人，不是 AI 学得最多的人。

⚡7 今天我讲三件事：
第一，他们在做什么。
第二，他们的商业模式为什么跑得通。
第三，你今晚就能做的第一步。
30 分钟讲完。
```
