# 10 维度评分标准

诊断模式逐项打分时参考此文件。

## 评分维度

### 1. 核心清晰度
> 听众离场后能否一句话转述核心信息？

| 分数 | 标准 |
|------|------|
| 1-3 | 听完不知道在讲什么，主题模糊或主题过多（>5个） |
| 4-6 | 大概知道主题但说不清核心，信息过载 |
| 7-8 | 能复述核心但表述不够精炼 |
| 9 | 听众能一句话转述 |
| 10 | 核心信息本身就是一句有传播力的话 |

**诊断信号**：数一下这场涉及了多少个独立主题。>5个=信息过载。

### 2. 结构可感知
> 听众随时知道"你在讲什么、讲到哪了"？

| 分数 | 标准 |
|------|------|
| 1-3 | 完全意识流，想到哪说到哪 |
| 4-6 | 有模块但缺过渡句，听众要自己猜"现在讲到哪了" |
| 7-8 | 有清晰模块、过渡句、开头有预告 |
| 9-10 | 开头有地图，每个转折都有路标，结尾回扣地图 |

**诊断信号**：搜索过渡句。"好，第一个讲完了"这类句子出现几次？0次=意识流。

### 3. 开头吸引力
> 前 60 秒是否制造了好奇心缺口？

| 分数 | 标准 |
|------|------|
| 1-3 | "大家好我今天讲…"直接自报家门 |
| 4-6 | 有互动（"扣个666"）但没有内容钩子 |
| 7-8 | 有好奇心缺口（反直觉事实/悬念/问题） |
| 9-10 | 好奇心缺口 + 结构地图 + 时间承诺，三件全中 |

**诊断信号**：前60秒是否包含让人想听下去的理由？

### 4. 情感共鸣度
> 全场有没有至少一个让听众情绪变化的时刻？

| 分数 | 标准 |
|------|------|
| 1-3 | 全程平淡或全程高能（一马平川=没有峰值） |
| 4-6 | 有互动但没有真实的情绪触动 |
| 7-8 | 有1-2个触动点（真实故事/自我暴露/扎心洞察） |
| 9-10 | 听众在某个瞬间"被击中"，事后还能回忆那个时刻 |

**诊断信号**：找到全场情绪最高点。如果找不到=没有设计峰值。

### 5. 具象化程度
> 抽象概念是否用具体画面承载？

| 分数 | 标准 |
|------|------|
| 1-3 | 全是抽象论述，没有案例/故事/数字 |
| 4-6 | 有案例但和论点脱节，或案例淹没在情绪词里 |
| 7-8 | 每个论点有案例+数据支撑 |
| 9-10 | 一句类比让抽象概念秒懂（"像自来水——以前只有有钱人喝得起"） |

**诊断信号**：统计"很牛逼""很厉害""很离谱"等模糊情绪词的出现频率。越多=具象化越差。

### 6. 可信度
> 听众相信你说的是真的吗？

| 分数 | 标准 |
|------|------|
| 1-3 | 全是观点，没有任何依据 |
| 4-6 | 有案例但来源模糊（"我有个朋友…"） |
| 7-8 | 有真实经历+具体数据+可验证信息 |
| 9-10 | 真实经历 + 坦诚承认局限 + 数据可验证 |

**诊断信号**：是否有"我不知道""我还没做到"这类坦诚表达？有=加分。

### 7. 节奏感
> 语速、能量、停顿是否有变化？

| 分数 | 标准 |
|------|------|
| 1-3 | 一马平川，从头到尾同一个能量水平 |
| 4-6 | 偶尔有变化但不是刻意设计 |
| 7-8 | 有明确的快慢交替，重要观点前有停顿 |
| 9-10 | "3-7-10"能量变化清晰，停顿设计精准 |

**诊断信号**：标记逐字稿中"停顿/降速"的位置。0处=没有节奏设计。

### 8. 听众中心度
> 从听众需求出发，还是从自己出发？

| 分数 | 标准 |
|------|------|
| 1-3 | 全程自说自话，"我要讲的是…" |
| 4-6 | 有互动问题但仍以自己为中心 |
| 7-8 | 从听众痛点切入，经常用"你是不是…" |
| 9-10 | 开场描述听众的问题，全程回应痛点，结尾给听众行动指令 |

**诊断信号**：第一句话描述的是听众的问题还是你要讲的主题？

### 9. 结尾力度
> 最后印象决定整体评价

| 分数 | 标准 |
|------|------|
| 1-3 | 草草收场（"差不多就这些了""时间到了"） |
| 4-6 | 有总结但没力度，没有行动召唤 |
| 7-8 | 有行动召唤，有钉子句 |
| 9-10 | 回扣开头 + 钉子句 + 明确行动指令，结尾经过设计 |

**诊断信号**：最后60秒是否有设计感？还是随机结束？

### 10. 记忆锚点
> 一周后听众还记得什么？

| 分数 | 标准 |
|------|------|
| 1-3 | 什么都记不住 |
| 4-6 | 记得某个案例但说不清要点 |
| 7-8 | 记得1-2句关键话 |
| 9-10 | 有一个刻意设计的"峰值时刻"，事后能复述 |

**诊断信号**：如果你只能记住这场分享的一个瞬间，是什么？如果答不出=没有记忆锚点。

## 总分解读

| 分数段 | 水平 | 建议 |
|--------|------|------|
| 80-100 | 专业级 | 微调节奏和钉子句即可 |
| 60-79 | 良好 | 有1-2个突出短板，针对性训练 |
| 40-59 | 及格 | 结构和信息密度是最大杠杆 |
| 20-39 | 需大幅改进 | 从"一个核心信息+3个模块"的基本功开始 |
| <20 | 重新设计 | 当前稿子不建议修补，建议从零重构 |

```
### 2. ...

## 训练优先级

```
