# 钉子句设计指南

钉子句 = 听一遍能记住、能转述给别人的短句。每个核心模块必须有一句。

## 四种基本公式

### 1. 对比反转
**结构**：X 不是 Y，是 Z

```
向上社交不是你认识谁，是谁愿意为你承担风险。
业务理解不是你知道多少，是你能把流量、产品、销售三个数字说清楚。
好的表达不是说得多，是让人记得住。
```

**适用场景**：纠正常见误解，重新定义概念。

### 2. 空间比喻
**结构**：用物理空间/动作映射抽象概念

```
情绪共振让你进门，但进门不等于上桌。
第一层叫基础盘，不叫天花板。
拿到了下一关的地图，但体力值不够，怪还是会打死你。
```

**适用场景**：阶段递进、层次关系。

### 3. 极简定义
**结构**：A 是 X，B 是 Y（用最少的字区分两个概念）

```
助理是功能，合伙人是身份。
学 AI 是消费，用 AI 是投资。
规则是人定的，原理是天定的。
```

**适用场景**：关键概念区分。

### 4. 数字对比
**结构**：用数字制造反差

```
稚嫩的人甜蜜度从 80 降到 20，成熟的人从 20 升到 80。
月入 3000 到月入 10 万——差距 30 倍，工具只是豆包。
1600 人参会，做复盘的不超过 1%。你做了，你就出圈。
```

**适用场景**：打破认知、制造冲击。

## 进阶公式

### 5. 条件句反转
**结构**：如果 X，那不是 Y，是 Z

```
如果你一直在学 AI，那不是在进步，是在逃避。
如果你把所有时间花在同频社交上，那不是社交强，是圈子小。
```

### 6. 排除法定义
**结构**：不是 A，不是 B，不是 C，是 D

```
不是更努力，不是更聪明，不是更幸运——是商业模式对了。
```

### 7. 画面钉
**结构**：一句话制造一个视觉画面

```
你在一个小系统里挣扎，就像在游泳池里练航海。
你对着 AI 许愿，就像对着 ATM 说"给我钱"。
```

## 质量检验

一句好的钉子句必须通过三个测试：

1. **转述测试**：听众能不能不看笔记，对朋友复述这句话？
2. **独立测试**：脱离上下文，这句话本身有没有力量？
3. **争议测试**：这句话是否会让一部分人不同意？（如果所有人都同意=废话）

## 常见错误

| 错误 | 为什么不好 | 改进 |
|------|-----------|------|
| "大家一定要重视这个" | 没有信息量 | 说具体重视什么、不重视会怎样 |
| "这个很重要很重要" | 重复不等于有力 | 用一个画面/数字说明为什么重要 |
| "希望大家都能做到" | 鸡汤感 | 给一个具体的第一步 |
| 太长（>25字） | 记不住 | 砍到15字以内 |
