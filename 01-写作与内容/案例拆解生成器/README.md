# 案例拆解生成器

## 这是什么

快速将案例/方法/工具拆解成结构化内容的 Skill。通过持续迭代优化拆解规则，提升产出质量。

## 什么时候用

- 看到一个好案例，想快速提炼核心逻辑
- 学习一个新方法/工具，想系统化理解
- 需要将复杂案例转化为可执行的步骤
- 需要分析案例的适用场景和潜在问题

## 快速开始

1. 说"案例拆解"或"拆解案例"激活 skill
2. 提供案例信息（名称、描述、目标受众）
3. 获得结构化拆解内容（一句话总结、适合谁、核心玩法、为什么有效、可能的坑、建议、延伸思考）

## 触发词

- 案例拆解
- 方法论拆解
- 工具拆解
- 拆解案例
- 分析方法

## 示例

用户："案例拆解"
AI："请提供案例信息：1) 案例/方法/工具名称 2) 简单描述 3) 目标受众（可选）"
用户："用AI做小红书矩阵号，用ChatGPT批量生成笔记，多账号发布，筛选爆款"
AI：[输出结构化拆解内容]
