## 小云雀（Seedance 2.0）— AI 视频生成

- 地址：https://xiaoyunque.jianying.com/（「沉浸式短片」模式）
- 单次生成 4-15s（5-10s 最稳定）；分辨率 720p-1080p；比例 16:9 / 9:16
- 提示词公式（七要素，意象级）：`[主体] + [环境/氛围] + [动作] + [镜头语言] + [音效] + [风格] + [画质]`；不写百分比坐标、逐帧时间表、hex/IRE。
- 分时段格式（>6s 强制）：0-3s / 3-6s / 6-10s / 10-15s 各写一段，每段一个主动作。
- @引用语法：`@图片1 作为首帧` / `参考 @视频1 的运镜` / `BGM参考 @音频1`
- 禁止：写实真人脸部、明星脸、未授权 IP、4-5s 塞多场景、模糊引用（写清「参考@视频1的运镜」而非「参考@视频1」）

## 参考帧与连续性

- 每镜生成后导出实际末帧，作为下一镜的 `@图片1` 或参考图；不要只用设计首帧图。
- 主角、关键道具、环境各留一张 canonical 参考图，每镜都传；文字锁定句只做补充。
- 相邻镜头比对：主体外形/比例、关键道具结构、环境色温/水体、主光形态、运动方向/速度。
- 漂移超过阈值先修，不要带着漂移进入下一镜。

## 原生音频

- 平台自带音频是 temp，不是最终声音。
- 审片时静音看画面；不要把 temp 音乐/音效当成节奏依据。
- 最终声音全部后期做；模型音频只作参考或占位。

## 能力样片与运镜

- 批量生成前先做 10-15 秒样片，验证主体、关键道具、环境色、运镜。
- 样片不过就简化镜头或换方案，不要只改词硬救。
- 每镜只给一个主导运镜；复合运镜拆成多镜或删掉。
- 接缝处做 0.3-0.5 秒速度渐变，不要用转场面板掩盖结构跳。

## 接缝处理

- 速度渐变：接缝前后 0.3-0.5 秒做 90-110% 速度渐变，掩盖运动跳变；只用于运动延续接缝。
- 运动模糊：硬切前镜末帧可加 2-3 帧运动模糊，柔化断裂感。
- 色调匹配：前镜末帧和后镜首帧并排看；色温/亮度差超阈值时做 0.3 秒关键帧过渡。
- ffmpeg 预检：进剪映前先抽每镜首末帧，生成并排对比图，定位问题接缝。

```bash
# 抽首帧 / 末帧（QC 用；末帧取不准时用帧号 select）
ffmpeg -y -i 素材/S01.mp4 -vf "select=eq(n\,0)" -frames:v 1 素材/qc/S01_first.png
ffmpeg -y -sseof -0.05 -i 素材/S01.mp4 -frames:v 1 素材/qc/S01_last.png

# 并排对比：前镜末帧 + 后镜首帧
ffmpeg -y -i 素材/qc/S01_last.png -i 素材/qc/S02_first.png -filter_complex hstack 素材/qc/seam_S01_S02.png
```

- 生成后 6 项自检、接缝校验和重做决策树见 `references/generation_qc.md`。

## ffmpeg — 程序化粗剪

- 用 Git Bash 跑（不是 PowerShell），Windows 路径先 `export MSYS2_ARG_CONV_EXCL="*"`
- 三件套：concat 拼接（filter_complex 统一 scale/format）→ eq 调色 → drawtext 字幕
- 中文字幕字体：`/c/Windows/Fonts/NotoSerifSC-VF.ttf`

## 剪映 / CapCut — 手动拼接

- ffmpeg 做不了的都在这：转场（只用硬切+交叉淡化）、旁白录音、BGM、并置蒙版、导出
- 导出：MP4 H.264，1920×1080，24fps，15-20 Mbps，AAC 320kbps
