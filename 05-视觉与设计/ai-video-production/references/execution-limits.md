# 模型执行边界与连续性协议

> 用法：写逐镜提示词、做接缝检查、写剪辑指令前读这一份。它是 SKILL.md 的补充，不替代叙事关卡，也不改变积分闸门。

---

## 1. 提示词精度分层

| 层 | 写什么 | 给谁 |
|---|---|---|
| 模型层（提示词） | 相对位置、一个主动作、一个主导运镜、色名、材质、光线方向 | 生成模型 |
| 验收层（验收表） | 百分比坐标、hex、IRE、帧号、容差 | 审片 / 后期 |

硬规则：

- 不把验收层的数字写进提示词。模型对精确坐标、逐帧时间表、色值的执行率低，写进去只会让提示词变长、重点变散。
- 提示词控制在「一镜一屏」。超长时先删与负面组重复的清单、重复的主体/道具锁定、可省的形容词；不要删首尾帧描述和主导运镜。
- 每个时段只写一个主动作；多个元素不要同时成形、同时运动；时间表不要重叠。
- 每镜只写一个主导运镜；复合运镜拆成多镜或删掉次要运动。

## 2. 连续性协议

相邻镜头不是靠文字锁定的，是靠**实际帧**接上的。

1. **实际末帧接力**：每镜生成后立刻导出实际末帧，作为下一镜的 `@图片1` 或参考图。不要只用设计首帧图。
2. **canonical 参考图**：主角、关键道具、环境各留一张 canonical 图，每镜都传。文字锁定句只做补充，不能替代参考图。
3. **五项比对**：主体外形/比例、关键道具结构、环境色温/水体、主光形态、运动方向/速度。任一项明显漂移，先修再往下做。
4. **连续性日志**：每镜记录用了哪张参考图、实际末帧路径、漂移项、处理方式。下一镜开工前先看日志。
5. **结构错误与参数错误分开**：主体变了、道具结构变了、朝向翻了、关键元素消失——结构错误，必须重生成；亮度/色温/构图差一点——参数错误，可以后期微调。不要用调色或转场掩盖结构错误。

## 3. 运镜简化

- 每镜一个主导运动：推、拉、摇、移、跟、升，只选一个。
- 禁止复合运镜：后拉 + 上仰 + 平移 + 减速停稳，模型执行不了，接起来会断。
- 相邻镜头的运动方向、速度要能接；接缝处做 0.3-0.5 秒速度渐变。
- 按动作剪，不按静止帧剪；切点前后各留 2-4 帧 handle。
- 不用转场面板掩盖结构跳；硬切 + 动作匹配优先。

## 4. 节奏与信息密度

- 先做 animatic：静帧 + 临时声音，按目标时长排一遍。
- 检查时长/信息密度曲线：避免连续多镜慢、最后一镜突然快；信息量大的镜头给足时长。
- 每镜只承担一个主要信息；信息过载的镜头拆成两镜。
- 用「正常速度、静音、手机屏」看一遍：观众能不能跟上？跟不上先调节奏，不要先加解释。

## 5. 原生音频

- 平台自带音频是 temp，不是最终声音。
- 审片时静音看画面；不要把 temp 音乐/音效当成节奏依据。
- 最终声音全部后期做；模型音频只作参考或占位，不能直接铺进成片。

## 6. 能力样片

- 批量生成前先做 10-15 秒样片，验证主体、关键道具、环境色、运镜。
- 样片不过就简化镜头或换方案，不要只改词硬救。
- 先测最难的动作/材质/光线，再测普通镜头；最难的过了，后面才稳。

## 7. 验收口径

- 以「正常速度、静音、手机屏」能看懂为准；观众能复述故事，比坐标对得上更重要。
- 坐标、hex、IRE 是 QC 指标，不是提示词指标。
- 结构错误：重生成，不后期硬救。
- 参数偏差：在容差内可后期调色/微调剪点；超出容差先重生成。

## 8. 常见失败模式与处理

| 现象 | 先判断 | 处理 |
|---|---|---|
| 精确坐标/时间表没执行 | 是提示词精度问题 | 把提示词降为意象级，精确值移到验收表 |
| 主体/道具/环境跨镜漂移 | 是结构问题 | 用实际末帧 + canonical 参考图；漂移大就重生成 |
| 水体/色温跳变 | 可能是参数问题 | 先统一色板/尾缀；切点做 3-6 帧亮度/色温关键帧 |
| 主光形态/数量变化 | 是结构问题 | 重生成；文字锁不定光，必须传参考图 |
| 运镜节奏断裂 | 是运动矢量问题 | 简化运镜；接缝做 0.3-0.5 秒速度渐变；按动作剪 |
| 信息密度忽高忽低 | 是节奏问题 | 先做 animatic，重排时长/拆镜 |
| 原生音频带偏节奏 | 是审片方法问题 | 静音审片；最终声音后期做 |
| 提示词太长、后段约束丢失 | 是长度问题 | 删重复清单/锁定句；保留首尾帧和主导运镜 |

## 9. 每镜生成后的 5 分钟检查

- [ ] 导出实际末帧，与下一镜设计首帧并排看
- [ ] 主体外形/比例一致
- [ ] 关键道具结构一致
- [ ] 环境色温/水体一致
- [ ] 主光形态/数量一致
- [ ] 运动方向/速度能接
- [ ] 静音看一遍，故事能跟上
- [ ] 有结构错误就重生成，不带着漂移进入下一镜
- [ ] 更新连续性日志
