# 项目：虚构角色智能体生成器

## 1. 项目目标

将用户提出的任意技能需求（技能Z），通过「小说A → 小说B → 角色C」的三层虚构嵌套，创造一个有世界观、有人格、有方法论的智能体System Prompt。

核心价值：比直接写System Prompt多了一层「角色厚度」——角色不是凭空捏造的，而是从一个完整的虚构宇宙中「生长」出来的。

## 2. 文件夹结构约定

| 路径 | 用途 |
|:---|:---|
| `SKILL.md` | **（本文件）** 项目说明书 |
| `outputs/` | 所有生成的虚构角色智能体产出 |
| `outputs/{技能名}-创造链路.md` | 完整创造链路（小说A/B/角色C/System Prompt） |
| `golden_rules.md` | 从反馈中提炼的创造规则 |

## 3. Skills

### Skill 1：生成虚构角色智能体

- **触发词**：`虚构角色`、`虚构智能体`、`角色生成`、`小说角色智能体`、`技能转角色`
- **动作**：

    **第一步：确认技能需求**

    1. 询问用户需要什么技能Z（如果用户已经说明则跳过）。
    2. 可选：询问用户对风格的偏好（科幻/奇幻/现实/赛博朋克/不限）。如果用户没有偏好，自行选择最适合技能Z气质的风格。

    **第二步：创造小说A**

    3. 根据技能Z，虚构一部全新的小说A。
       - 包含：小说名称、世界观设定、核心主题。
       - 要求：小说A的世界观要与技能Z有隐喻关系（不是直接关系）。
       - 例：技能Z是「数据分析」→ 小说A可能是一个「万物皆有纹理，读懂纹理就能预知未来」的世界。

    **第三步：创造小说B**

    4. 小说A的主人公本身就是另一部小说B。
       - 包含：小说B的名称、故事梗概。
       - 要求：小说B与小说A之间要有巧妙的元叙事嵌套关系。

    **第四步：创造角色C**

    5. 虚构小说B的主人公C。
       - 包含：姓名、背景、性格、为何擅长技能Z。
       - 要求：角色C的能力设定要自然地服务于技能Z，不能生硬。
       - 角色要有记忆点和独特性。

    **第五步：生成System Prompt**

    6. 为角色C创建完整的System Prompt，包含以下模块：
       - 身份背景（含世界观）
       - 核心能力（3-5项，与技能Z强相关）
       - 工作方式（角色如何运用技能Z的具体方法论）
       - 性格特质（影响工作风格的性格特点）
       - 交互风格（如何与用户对话）
       - 使命（作为智能体要达成的目标）

    **第六步：输出与保存**

    7. 按输出格式完整输出创造链路和System Prompt。
    8. 保存到 `outputs/{技能名}-创造链路.md`。
    9. 给出完整绝对路径。

### Skill 2：查看已有角色

- **触发词**：`查看角色`、`角色列表`
- **动作**：
    1. 扫描 `outputs/` 文件夹。
    2. 列出所有已创建的虚构角色智能体。
    3. 每个角色显示：技能Z、角色名、来自哪部小说。

## 4. 输出格式

```
📚 创造链路
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
技能需求: [技能Z]

1️⃣ 虚构小说 A: 《[小说名]》
   [2-3句话描述小说A的世界观和主题]

2️⃣ 虚构小说 B: 《[小说名]》
   [说明：小说A的主人公就是这部小说B]
   [2-3句话描述小说B的故事梗概]

3️⃣ 虚构角色 C: [角色名字]
   [说明：小说B的主人公]
   [2-3句话描述角色背景、性格、为何擅长技能Z]

🤖 智能体 System Prompt
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
你是 [角色C名字]，来自《[小说B]》。

## 身份背景
[详细的角色背景故事，包含其世界观]

## 核心能力
[列出与技能Z相关的3-5项核心能力]

## 工作方式
[描述角色如何运用技能Z的具体方法论]

## 性格特质
[影响其工作风格的性格特点]

## 交互风格
[如何与用户对话、提供帮助]

## 使命
[作为智能体要达成的目标]

当用户寻求帮助时，以 [角色C] 的身份和方式，运用 [技能Z] 提供专业支持。
```

## 5. 创造原则（必须遵守）

- 所有内容（小说A、小说B、角色C）都是**原创虚构**，禁止使用现有文学作品、影视作品、游戏角色
- 小说A的世界观与技能Z之间是**隐喻关系**，不是直接映射
- 小说A和小说B之间要有巧妙的**元叙事嵌套**——不是简单的「书中书」，而是两层叙事之间有呼应和张力
- 角色C的能力必须从其人生经历中**自然生长**出来，不能「天赋异禀」一笔带过
- System Prompt要**可直接使用**——复制粘贴到任何AI对话框就能用
- 富有想象力，但确保角色有**内在一致性**

## 6. 重要约束

- 严格按本文件定义的步骤执行，不要跳步
- 每次生成前，先读取 `golden_rules.md`（如存在），确保遵守所有积累的规则
- 保存文件后给出完整绝对路径
- 不要使用AI味的表达（排比、对仗、「本质上」等）
- System Prompt中的角色语言要符合角色设定，不要千篇一律
