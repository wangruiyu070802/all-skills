# Visual Style Prompt — 视觉风格学习与配图提示词生成

## 概述

这个skill把"学习一个创作者的配图风格并复现它"这件事，拆解成两个独立的、可操作的步骤：

1. **风格解码**：把视觉风格翻译成精确的语言描述（解决"我说不清楚为什么好看"的问题）
2. **场景设计**：把抽象的文章/内容主题转化为具象的画面（解决"我不知道该画什么"的问题）

最终输出：可以直接交给 Midjourney / DALL-E / Lovart / Stable Diffusion 等工具使用的完整提示词。

---

## 第一步：风格解码（Style Decoding）

### 目标
把用户喜欢的视觉风格，从"感觉"变成"可描述的参数"。

### 操作流程

#### 1.1 收集参考素材
向用户收集以下信息（至少需要其中一项）：

- **创作者网站URL**：用于抓取和分析页面上的配图
- **参考图片**：用户上传的具体图片（3-5张最佳）
- **创作者名字 + 平台**：用于搜索其公开内容

> 关键原则：至少分析5张以上的图片才能提取出"风格"，而不是"单张图片的特征"。

#### 1.2 用「七维分析框架」拆解风格

对每张参考图片，从以下7个维度进行分析：

| 维度 | 分析什么 | 示例描述 |
|------|----------|----------|
| **1. 色彩系统** | 背景色、主色、强调色、饱和度、对比度 | "纯黑背景#000，白色发光线条，无中间灰度" |
| **2. 线条/笔触** | 线条粗细、密度、风格（手绘/机械/发光） | "极细白色线条，有轻微光晕，类似线框图" |
| **3. 主体类型** | 人物、物体、抽象形状、文字 | "几乎每张都有一个人物在做某个动作" |
| **4. 构图方式** | 主体位置、留白比例、视线引导 | "主体居中，周围70%是黑色留白" |
| **5. 叙事手法** | 是否讲故事、隐喻方式、情绪基调 | "用具象动作隐喻抽象概念，戏剧性强" |
| **6. 细节密度** | 简约还是复杂、细节集中在哪里 | "主体细节丰富，背景极简" |
| **7. 整体气质** | 给人的感受关键词（3-5个） | "深邃、力量感、哲学、古典、永恒" |

#### 1.3 提取「风格DNA」

分析完所有图片后，提炼出跨图片的共性特征。输出格式：

```
## 风格DNA：[创作者名字]

### 视觉参数（每次生成图片时复用）
- 背景：[具体颜色/质感]
- 线条/笔触：[具体描述]
- 色彩范围：[允许的颜色]
- 对比度：[高/中/低]
- 细节风格：[具体描述]
- 质感/纹理：[具体描述]

### 构图规则
- 主体位置：[居中/偏左/偏右]
- 留白比例：[百分比]
- 元素数量：[通常几个核心元素]
- 视线引导：[如何引导观众视线]

### 叙事模式
- 是否包含人物：[是/否/有时]
- 人物状态：[动态动作/静态姿势/剪影]
- 隐喻方式：[具象叙事/象征符号/抽象图形]
- 情绪基调：[关键词]

### 常见场景模板（从参考图中提取的反复出现的构图模式）
- 模板A：[描述]，用于表达[什么类型的概念]
- 模板B：[描述]，用于表达[什么类型的概念]
- 模板C：[描述]，用于表达[什么类型的概念]
```

#### 1.4 生成「风格基底提示词」

将风格DNA浓缩成一段可以直接复用的提示词前缀（约50-80词），每次生成图片时都附加这段。

示例（Dan Koe风格）：
```
Pure black background (#000000). Extremely fine white line art with soft luminous glow effect. High contrast, no gray tones. Wireframe aesthetic reminiscent of neural networks and technical blueprints. Single focal subject centered in frame with 60-70% negative black space surrounding it. Dramatic, narrative composition. Lines are thin and precise with subtle light bloom. 16:9 horizontal format.
```

## 第二步：场景设计（Scene Design）

### 目标
把用户的文章/内容主题，从抽象概念转化为一个"能看见的画面"。

### 操作流程

#### 2.1 理解内容主题

向用户确认：
- 这个内容的**核心概念**是什么？（一句话）
- 这个内容想传达的**情绪/感受**是什么？（比如：力量、希望、挣扎、突破、专注）
- 这个图片的**用途**是什么？（博客封面、资源卡片、社交媒体、演讲幻灯片）

#### 2.2 用「比喻转化法」设计画面

这是整个skill最核心的步骤。分三轮思考：

**第一轮：找比喻**
问自己：这个抽象概念，在现实生活中"像什么"？

| 抽象概念 | 像什么？ | 为什么像？ |
|----------|----------|------------|
| 创业的艰难 | 像攀登陡峭的山 | 都是孤独的、吃力的、看不到顶的 |
| 反馈回路 | 像西西弗斯推石头 | 都是循环的、重复的、但每次有进步 |
| 个人品牌 | 像灯塔 | 都是在黑暗中持续发出信号、吸引他人 |
| 内容系统 | 像种一棵树 | 都是需要根基、会生长、会分支扩展 |
| 深度工作 | 像潜水 | 都是沉入深处、隔绝外界干扰 |

**第二轮：设计场景**
把比喻变成一个具体的画面，包含：
- **谁**：什么样的人物（性别、姿态、穿着轮廓）
- **在做什么**：一个明确的动词（攀爬、推动、种植、航行、雕刻）
- **在哪里**：什么环境（山顶、海上、工作室、悬崖边）
- **关键道具**：一个核心物体（巨石、船、树、灯塔）
- **光线/氛围**：光从哪里来，什么情绪（从上方、从远处、从物体内部）

**第三轮：检验隐喻**
问自己两个问题：
1. 如果一个完全不知道文章主题的人看到这张图，他能大概猜到这是关于什么的吗？→ 如果不能，隐喻不够直观
2. 这个场景有"动作感"和"张力"吗？→ 如果人物只是站着，缺乏戏剧性

#### 2.3 常用比喻库

以下是经过验证的、视觉效果好的概念→场景映射：

**成长/进步类：**
- 成长 → 人攀爬阶梯/山峰
- 突破 → 人破墙而出 / 人从裂缝中挤出
- 蜕变 → 蝴蝶破茧 / 人脱下旧壳

**挑战/困难类：**
- 压力 → 人背负巨石
- 逆境 → 人在暴风浪中划船
- 迷茫 → 人在十字路口 / 人在迷宫中

**创造/建设类：**
- 创作 → 人用锤子雕刻石像
- 系统搭建 → 人种下树苗，树长成大树
- 精细打磨 → 人用放大镜检查作品

**选择/决策类：**
- 选择 → 人站在两扇门前
- 觉醒 → 红蓝药丸（Matrix风格）
- 转折 → 人在悬崖边转身

**影响力/传播类：**
- 个人品牌 → 人站在高处，举火把/灯
- 教学 → 人向一群人展示地图
- 影响力 → 人身后投射巨大的影子

**专注/深度类：**
- 深度工作 → 人伏案，周围万物静止
- 冥想 → 人坐在巨大空间中心
- 专注 → 相机镜头聚焦于一个点

**工具/技术类：**
- 工具箱 → 人打开发光的箱子
- AI/技术 → 人与机械结构互动（触碰齿轮、面对巨大大脑）
- 编程 → 人在巨大的石碑上刻字

## 第三步：组合输出（Prompt Assembly）

### 3.1 提示词结构

最终提示词 = 风格基底 + 场景描述 + 技术参数

```
[风格基底提示词，约50-80词]

[场景描述，约40-60词，包含：人物、动作、环境、核心道具、光线]

[技术参数：尺寸比例、其他要求]
```

### 3.2 场景描述的写作原则

1. **用动词开头**：先说人物在做什么，再说环境
   - "A person climbing a steep cliff face, reaching upward toward a glowing light..."
   - "There is a cliff with a person on it..."

2. **具体胜于模糊**：
   - "kneeling with both hands gripping the edge of an open chest"
   - "a person near a box"

3. **一个焦点**：只描述一个核心场景，不要塞入多个不相关的元素
   - 一个人 + 一个巨石
   - 一个人 + 巨石 + 树 + 河流 + 鸟 + 太阳

4. **明确光线来源**：光线方向极大影响画面情绪
   - 从下方照亮 → 神秘、力量
   - 从远处/上方 → 希望、目标
   - 从物体内部 → 发现、启示

5. **描述姿态而非情绪**：AI更擅长画姿势，不擅长画情绪
   - "body leaning forward, arms straining, muscles tense"
   - "looking determined and hopeful"

### 3.3 输出示例

**主题：反馈回路**

```
Pure black background (#000000). Extremely fine white line art with soft 
luminous glow effect. High contrast, no gray tones. Wireframe aesthetic. 
Single focal subject with 60-70% negative black space.

A person pushing a massive circular wheel or gear from behind, body 
leaning forward with both hands pressed against the wheel's edge, feet 
braced against the ground. The wheel is partially embedded in the ground, 
suggesting weight and resistance. Faint circular motion lines suggest 
the wheel has been turning repeatedly. The person's posture shows 
sustained effort — not starting, but continuing.

16:9 horizontal format.
```

## 工作流总结

```
用户提供参考（URL/图片/创作者名字）
        ↓
  [风格解码] 七维分析 → 风格DNA → 风格基底提示词
        ↓
  用户提供内容主题列表
        ↓
  [场景设计] 比喻转化法 → 具体场景描述
        ↓
  [组合输出] 风格基底 + 场景描述 + 技术参数 = 完整提示词
        ↓
  生成图片 → 用户反馈 → 迭代优化
```

---

## 与用户沟通的注意事项

1. **不要假设用户懂设计术语**。说"画面里东西的摆放位置"而不是"构图"；说"明暗对比"而不是"chiaroscuro"。如果要用术语，附上简单解释。

2. **先对齐再动手**。在生成任何图片之前，先把"风格DNA"和每张图的"场景描述"用文字呈现给用户确认。文字对齐比图片返工成本低得多。

3. **一张一张来**。不要一次生成7张图。先生成1张，确认方向正确后，再批量生成其余的。

4. **用对比帮助用户表达**。如果用户说"不对劲"但说不清哪里不对，给两个不同方向的选项让他选，通过排除法缩小范围。

5. **记录迭代历史**。每次用户说"不够好"时，记录他不满意的点，逐渐建立这个用户的审美偏好档案。

## 常见失败模式与避免方法

| 失败模式 | 原因 | 解决方法 |
|----------|------|----------|
| 图片太抽象，没有故事感 | 只描述了符号，没有设计场景 | 必须包含人物+动作+环境 |
| 图片元素太多太杂 | 试图在一张图里表达太多概念 | 严格限制：1个人 + 1个核心道具 + 1个环境 |
| 风格不像参考 | 只学了表面（颜色），没学深层（叙事方式） | 七维分析必须完整，特别是"叙事手法"维度 |
| 隐喻看不懂 | 比喻太个人化，不够普世 | 用检验步骤测试：陌生人能猜出主题吗？ |
| 人物姿态僵硬 | 描述了情绪而非动作 | 用具体的身体姿势描述代替情绪形容词 |
| 每张图看起来都一样 | 风格基底太强，场景变化太小 | 确保每张图的核心动词和道具都不同 |
