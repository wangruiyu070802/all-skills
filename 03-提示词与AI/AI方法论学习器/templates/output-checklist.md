# 输出检查清单

每次完成提炼后，使用这个清单确保输出完整。

---

## ✅ 必须输出的内容

### 1. 提炼结果文件

- [ ] 文件已保存到正确位置
- [ ] 文件命名符合规范（见 [文件命名规则](../rules/file-naming.md)）
- [ ] 包含所有必需的元信息（来源、日期、适用场景）

### 2. 价值评估

- [ ] 核心价值是什么？
- [ ] 可以解决我的哪些问题？
- [ ] 优先级：高/中/低

### 3. 行动建议

选择以下一项或多项：

- [ ] **建议做成skill**
  - 原因：[...]
  - 下一步：调用 skill-creator

- [ ] **建议立即应用到**
  - 具体skill/工作流：[...]
  - 如何应用：[...]

- [ ] **建议作为参考资料**
  - 用途：[...]
  - 关联的skill：[...]

### 4. 更新索引

- [ ] 在 `resources/INDEX.md` 中添加条目
- [ ] 在 `ai-zone/INDEX.md` 中更新（如果创建了新skill）

---

## 📋 质量检查

### 内容完整性

- [ ] 核心观点清晰（一句话能说明白）
- [ ] 具体做法可执行（不是抽象描述）
- [ ] 底层逻辑说清楚了（为什么有效）
- [ ] 适用场景明确（什么时候用/不用）

### 可复用性

- [ ] 提取了可复用的技巧（不是照搬）
- [ ] 有具体的例子（不是空话）
- [ ] 可以应用到多个场景

### 关联性

- [ ] 思考了和现有skill/方法论的关系
- [ ] 标注了可以互相补充的地方
- [ ] 识别了可能的冲突

---

## 🎯 完成标志

当以上所有项都打勾后，才算完成提炼任务。
