# AI 对话

## 基本对话

- 在输入框中输入消息，按 Enter 发送
- Shift+Enter 换行
- 支持多轮连续对话，AI 会记住上下文
- 每个工作区下可创建多个独立对话
- 对话自动保存，按时间分组显示（今天/昨天/更早）
- 右侧有日期时间线导航，可以快速跳转到特定日期的消息

### 操作步骤：新建对话

1. 点击侧栏顶部第一个按钮「新建对话」（加号图标）
2. 主区域切换到空白对话界面
3. 在底部输入框中输入你的问题
4. 按 Enter 发送，AI 开始回复

### 操作步骤：切换对话

1. 在侧栏「最近对话」区域找到目标对话
2. 点击对话标题即可切换过去
3. 如果对话较多，可使用侧栏顶部第二个按钮「搜索」全文搜索历史对话

## 消息格式与渲染

AI 回复支持以下富文本格式：

- **Markdown**：标题、粗体、斜体、列表、引用、表格等
- **代码块**：语法高亮，支持多种编程语言
- **LaTeX 数学公式**：行内和块级公式
- **Mermaid 图表**：流程图、时序图、甘特图等
- **SVG/Canvas 可视化**：图形绘制
- **HTML 预览**：交互式 HTML 内容

## 文件附件

### 支持的文件类型
- 文本/代码文件：txt, md, py, js, ts, json, yaml, html, css 等
- 图片：PNG, JPG, GIF, WebP（带预览）
- 文档：PDF, DOCX, XLSX, PPTX, CSV
- 数据库：SQLite（可浏览表结构和数据）
- 视频：支持播放预览

### 操作步骤：添加文件附件

**方式一：点击附件按钮**
1. 点击输入框左侧工具栏中的回形针按钮
2. 在弹出的文件选择器中选择文件
3. 文件出现在输入框上方的附件栏中（显示文件名，可点 X 移除）
4. 输入消息后按 Enter 连同附件一起发送

**方式二：拖拽文件**
1. 从文件管理器（Finder / 资源管理器）中选中文件
2. 拖拽到对话区域
3. 松开鼠标，文件自动添加到附件栏

**方式三：粘贴图片**
1. 复制一张图片（截图或从其他应用中复制）
2. 在输入框中按 Ctrl/Cmd+V
3. 图片预览出现在附件栏中

**方式四：@引用工作区文件**
1. 在输入框中输入 `@`
2. 弹出工作区文件列表，支持模糊搜索
3. 选择要引用的文件，文件会作为上下文附件添加
4. 也可以选择整个文件夹路径，AI 会按需浏览其中的文件

## 文件预览

对话中提到的或 AI 生成的文件可以直接预览：

| 文件类型 | 预览能力 |
|----------|----------|
| CSV/XLSX | 表格形式展示 |
| PPTX | 幻灯片导航浏览 |
| PDF | 文档阅读器 |
| 图片 | 缩略图 + 尺寸信息 |
| 视频 | 播放器 |
| HTML | 沙箱渲染 |
| 代码文件 | 语法高亮 |
| SQLite | 表浏览器 + 查询 |

### 操作步骤：预览 AI 产出的文件

1. AI 回复中如果生成了文件，消息中会显示文件卡片
2. 点击文件卡片，右侧弹出预览面板
3. 根据文件类型自动选择对应的预览方式
4. 可以点击「在系统应用中打开」用默认程序打开文件

### 操作步骤：查看 AI 修改的文件

1. AI 修改文件后，消息中会显示文件变更卡片，标注创建/编辑/删除操作
2. 右侧面板会自动弹出并切换到「Changes」标签
3. 面板中列出所有被修改的文件
4. 点击文件名可查看修改内容（diff 对比）
5. 超过 6 个文件时会折叠显示，点击「展开更多」查看全部

## 扩展思考（Extended Thinking）

AI 可以展示推理过程，帮助用户了解回答的思路。

### 操作步骤：调整思考预算

1. 在输入框左侧工具栏中找到灯泡按钮
2. 点击后弹出思考预算选择菜单
3. 选择一个级别：
   - **自动**：AI 自行决定是否需要思考
   - **关闭**：不展示思考过程
   - **低**：简短思考
   - **中**：适度思考
   - **高**：深度推理，适合复杂问题
4. 选择后立即生效，后续 AI 回复会按选定级别展示思考过程
5. 思考过程在回复中以可折叠区块形式显示，点击可展开/收起，并显示思考耗时

## 网络搜索

AI 可以在对话中实时搜索互联网获取最新信息。

### 操作步骤：开启网络搜索

1. 在输入框左侧工具栏中找到搜索图标按钮
2. 点击开启/关闭网络搜索（按钮高亮表示已开启）
3. 开启后 AI 会在需要时自动搜索互联网
4. 搜索结果会整合到 AI 的回复中

> 需要先在设置 → 搜索服务中配置搜索提供商和 API Key 才能使用。

## 工具调用

AI 在对话中可以使用多种工具完成任务：

### 文件操作
- **读取文件**：查看文件内容
- **写入文件**：创建新文件
- **编辑文件**：修改已有文件（显示 diff 对比）
- **查找文件**：按模式搜索
- **搜索内容**：在文件中搜索文本

### 命令执行
- **终端命令**：执行 Shell 命令，显示输入和输出
- 命令状态显示：运行中 / 完成 / 错误

### 网络操作
- **网络搜索**：搜索互联网信息
- **获取网页**：读取网页内容

### 子代理（后台任务）
- AI 可以启动子代理在后台并行处理复杂任务
- 子代理状态可追踪：等待中 / 运行中 / 已完成 / 错误
- 每个子代理有独立的工具调用历史
- 完成后结果会显示在主对话中

### 权限控制

**操作步骤：配置权限模式**
1. 点击侧栏底部的头像图标 → 打开「设置」
2. 点击左侧「通用」标签
3. 找到「权限模式」设置项
4. 选择模式：
   - **普通模式**：AI 执行危险操作时需要你手动确认
   - **YOLO 模式**：AI 自动执行所有操作（需谨慎开启）
5. 可在「命令白名单」中配置允许自动执行的命令

## 对话管理

### 操作步骤：收藏对话

1. 在侧栏「最近对话」中找到目标对话
2. 右键点击对话标题
3. 选择「收藏」，对话会置顶显示在列表顶部
4. 再次右键选择「取消收藏」可移除置顶

### 操作步骤：归档对话

1. 在侧栏「最近对话」中找到目标对话
2. 右键点击对话标题
3. 选择「归档」，对话进入只读归档状态
4. 归档后的对话不再显示在主列表中
5. 可以通过搜索找到归档对话并取消归档

### 操作步骤：搜索对话

1. 点击侧栏顶部第二个按钮「搜索」（放大镜图标）
2. 弹出搜索对话框
3. 输入关键词，自动搜索所有对话内容
4. 点击搜索结果即可跳转到对应对话

### 操作步骤：删除对话

1. 在侧栏「最近对话」中找到目标对话
2. 右键点击对话标题
3. 在弹出的右键菜单中选择「删除」

### 操作步骤：页内查找

1. 在对话页面按 Cmd+F（Mac）或 Ctrl+F（Windows）
2. 顶部弹出查找栏
3. 输入搜索内容，匹配项高亮显示
4. 使用上/下箭头切换匹配项，显示当前/总匹配数

### 操作步骤：导出对话为图片

1. 在对话中选择想要导出的消息（可多选）
2. 选中后顶部出现分享操作栏
3. 可选择是否开启「脱敏」模式（隐藏敏感信息）
4. 点击「下载图片」保存为 PNG/JPG
5. 也可直接复制图片到剪贴板

## 消息队列

支持连续发送多条消息，系统会按顺序处理。

### 操作步骤：连续发送消息

1. 在 AI 回复过程中，你可以继续输入新消息
2. 按 Enter 发送，消息进入队列（输入框上方显示队列状态）
3. 也可以点击输入框右侧的「加入队列」按钮（列表加号图标）
4. AI 会按顺序依次处理队列中的消息
5. 最多支持 5 条消息排队
6. 可以编辑队列中未处理的消息、暂停/恢复队列、或清空整个队列

### 操作步骤：取消 AI 回复

1. 在 AI 正在回复时，输入框右侧的发送按钮变为「停止」按钮（方块图标）
2. 点击即可中断当前回复

## 在对话中使用技能

### 操作步骤：启用/选择技能

**方式一：通过工具栏**
1. 点击输入框左侧工具栏中的「技能」按钮（齿轮图标，右上角显示已启用数量）
2. 弹出技能选择面板，列出所有已安装的技能
3. 勾选要在本次对话中使用的技能
4. 关闭面板，选中的技能显示在附件栏中

**方式二：通过斜杠命令**
1. 在输入框中输入 `/`
2. 弹出技能快速选择菜单
3. 选择要调用的技能
4. 技能指令自动填入输入框

> 技能选择是按对话标签页隔离的，切换标签页时会保存/恢复各自的技能选择。

## 切换模型

### 操作步骤：在对话中切换 AI 模型

1. 在输入框右侧找到模型选择器（显示当前模型名称和提供商图标）
2. 点击打开下拉菜单
3. 模型按提供商分组显示
4. 选择目标模型，立即切换

> 模型切换是按对话隔离的，在当前对话中切换模型不会影响其他对话的模型选择。每个对话独立记忆自己的模型和提供商。
