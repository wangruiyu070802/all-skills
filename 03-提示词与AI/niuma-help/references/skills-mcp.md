# 技能系统

## 技能系统

技能（Skill）是牛马AI的扩展能力系统，类似插件。每个技能赋予 AI 特定领域的专业能力。

### 什么是技能

技能是一组预定义的指令和工具配置，安装后 AI 可以使用该技能完成特定类型的任务。例如：
- 公众号文章写作技能
- 数据分析技能
- 图片生成技能
- PPT 制作技能
- 视频创作技能

### 技能来源

技能按优先级从三个位置加载（同名技能高优先级覆盖低优先级）：
1. **项目级**：当前工作区 `.claude/skills/` 下的技能（最高优先级）
2. **插件级**：通过 Claude Code 插件安装的技能
3. **用户级**：手动安装或从市场下载的技能

### 操作步骤：浏览和安装技能（雇佣牛马）

1. 点击侧栏顶部第四个按钮「雇佣牛马」（商店图标）
2. 主区域切换为雇佣牛马页面
3. 顶部有两个标签：
   - **市场**：浏览所有可用的社区技能
   - **已安装**：管理已安装的技能
4. 使用搜索栏输入关键词搜索技能，或使用分类筛选下拉菜单
5. 技能按分类展示：开发、写作、分析、自动化、设计、文档排版、安全、视频生成、飞书集成、其他
6. 找到想要的技能后，点击技能卡片查看详情（描述、版本、安装次数、标签）
7. 点击「安装」按钮，一键安装到本地
8. 安装完成后可在「已安装」标签中查看

### 操作步骤：从本地安装技能

1. 进入雇佣牛马页面（侧栏「雇佣牛马」按钮）
2. 点击页面右上角的 **···**（更多菜单）
3. 选择安装方式：
   - **从 ZIP 文件安装**：选择本地 ZIP 压缩包
   - **从文件夹安装**：选择本地技能文件夹
4. 等待安装完成

### 操作步骤：在对话中启用技能

1. 在对话输入框左侧工具栏中找到「技能」按钮（右上角显示已启用数量的徽章）
2. 点击弹出技能选择面板
3. 面板有两个标签页：「全部技能」和「已启用」（显示数量）
4. 支持搜索技能名称或描述
5. 勾选你需要在本次对话中使用的技能
6. 可使用「全选」或「清空」快捷操作
7. 关闭面板，已选技能以标签形式显示在输入框上方的附件栏中
8. 正常对话即可，AI 会根据需要自动调用已启用的技能

> 技能选择按对话标签页隔离，切换标签页时各自保存/恢复技能选择。

### 操作步骤：通过斜杠命令快速使用技能

1. 在输入框中输入 `/`（斜杠）
2. 弹出技能快速选择菜单，列出可用技能命令
3. 选择目标技能
4. 技能指令自动填入输入框
5. 补充你的具体需求后按 Enter 发送

### 操作步骤：卸载技能

1. 进入雇佣牛马页面（侧栏「雇佣牛马」按钮）
2. 切换到「已安装」标签
3. 找到要卸载的技能
4. 点击技能卡片上的「卸载」按钮

> 卸载后系统会记录，防止自动重新安装。如果该技能被项目或定时任务引用，卸载时会有提示。

### 操作步骤：发布自己的技能

1. 进入雇佣牛马页面
2. 点击页面右上角的 **···** 更多菜单
3. 选择「上传技能」
4. 选择技能文件/文件夹
5. 填写技能元数据：
   - 展示名称和描述
   - 分类选择
   - 版本号
   - 图标（上传图片，自动裁剪为 128px 方形）
6. 提交后等待管理员审核，审核通过后在雇佣牛马中公开
7. 可在雇佣牛马中查看自己发布的技能状态和安装统计
