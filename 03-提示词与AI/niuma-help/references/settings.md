# 设置与个性化

## 操作步骤：打开设置

1. 在侧栏最底部找到用户头像图标
   - 已登录：显示用户头像或名字首字母
   - 游客模式：显示「G」头像和「游客模式」标签
2. 点击头像图标
3. 弹出「设置」对话框
4. 左侧有多个标签页，右侧显示对应设置内容
5. 修改完成后点击右下角「完成」保存

## 个性化

### 操作步骤：设置用户名称和工作描述

1. 打开设置 → 点击左侧「个性化」标签（人像图标）
2. 在「姓名」输入框中填入你的名字
   - 设置后，首页问候语会显示你的名字（如"Yangyi 晚上好"）
3. 在「工作描述」输入框中描述你的工作内容
   - AI 会根据此信息更好地理解你的需求和习惯
4. 在「全局提示词」输入框中添加对 AI 的通用指令（可选）
   - 这里的提示词会自动附加到所有对话中
5. 点击「完成」保存

## 通用设置

### 操作步骤：设置全局唤起快捷键

1. 打开设置 → 点击左侧「通用」标签（齿轮图标）
2. 找到「快捷键唤起小窗」设置项
3. 点击当前快捷键显示区域（默认显示 Command+W）
4. 按下新的快捷键组合
5. 新快捷键立即生效，在任何应用中都可按此快捷键唤起牛马AI快速输入窗口

### 操作步骤：设置语音输入快捷键

1. 打开设置 → 点击左侧「通用」标签
2. 找到「语音输入快捷键」设置项
3. 先打开旁边的开关（启用语音快捷键功能）
4. 点击快捷键显示区域
5. 按下想要的快捷键组合
6. 设置完成后，在任何界面中按住该快捷键即可开始录音，松开自动转文字

### 操作步骤：配置其他通用选项

1. 打开设置 → 点击左侧「通用」标签
2. 根据需要调整以下开关：
   - **菜单栏**：是否在系统菜单栏显示应用图标
   - **开机自动启动**：是否在电脑登录时自动启动牛马AI
   - **通知**：是否接收系统桌面通知
   - **自动检查更新**：是否自动检测新版本
   - **自动下载更新**：检测到新版本后是否自动下载
3. 还可以配置：
   - **权限模式**：普通模式（需确认）/ YOLO 模式（自动执行）
   - **命令白名单**：允许 AI 自动执行的命令列表

### 操作步骤：恢复默认设置

1. 打开设置 → 点击左侧「通用」标签
2. 点击左下角的「恢复默认」按钮
3. 所有通用设置恢复为初始值

## 主题设置

### 操作步骤：切换主题外观

1. 打开设置 → 点击左侧「主题」标签
2. 选择外观模式：
   - **浅色**：白天使用的亮色界面
   - **深色**：护眼暗色界面
   - **跟随系统**：自动跟随操作系统的深浅模式
3. 选择颜色主题（11 种可选）：
   - 默认、黄昏、海洋、森林、复古、霓虹、青柠、专业、活力、自然、优雅
4. 调整聊天字体大小（13-18px，默认 14px）
5. 可选开启「减少动画」（降低 GPU 占用，提升流畅度）

### 操作步骤：配置工具调用显示

1. 在主题设置中找到工具调用相关选项
2. **显示工具调用**：开启后可以看到 AI 使用了哪些工具
3. **默认展开工具调用**：开启后工具调用详情自动展开，无需手动点击

## AI 洞察

牛马AI 可以定期自动生成工作洞察报告。

### 操作步骤：配置每日回顾

1. 打开设置 → 点击左侧「AI 洞察」标签
2. 找到「每日回顾」区域
3. 开启每日回顾开关
4. 设置执行时间（默认早上 8:00）
5. 选择要包含的模块：
   - **会话摘要**：今天做了什么
   - **未回复消息**：有哪些问题没回答
   - **使用统计**：Token 用量和成本
   - **代码生成统计**：构建了什么

### 操作步骤：配置深度洞察

1. 在 AI 洞察设置中找到「深度洞察」区域
2. 设置周期：每周 / 每两周 / 每月
3. 选择执行日（星期几或每月几号）
4. 选择要包含的模块：
   - **路线图分析**：项目进展评估
   - **趋势分析**：使用模式洞察
   - **研究摘要**：探索的主题总结
5. 可选择是否包含 Claude Code 对话历史
6. 可选择特定模型用于生成洞察
7. 可配置将洞察推送到外部通知渠道

## 搜索服务设置

配置 AI 对话中的网络搜索能力。

### 操作步骤：配置搜索提供商

1. 打开设置 → 点击左侧「搜索服务」标签
2. 支持的搜索提供商：
   | 提供商 | 说明 |
   |--------|------|
   | Tavily | AI 优化搜索（推荐首选） |
   | Exa | 语义搜索，适合学术内容 |
   | Brave Search | 隐私友好的通用搜索 |
   | 秘塔搜索 (Metaso) | 中文 AI 搜索（无需翻墙） |
   | SerpAPI | Google 搜索结果 API |
   | Serper | 快速 Google 搜索 API |
   | Bing Search | 微软必应搜索（国内可用） |
   | Google CSE | Google 自定义搜索引擎（需额外配置搜索引擎 ID） |
   | Firecrawl | 搜索 + 结构化网页抓取 |
3. 找到想要的搜索提供商
4. 填入 API Key
5. 开启该提供商
6. 可同时启用多个搜索提供商

## 网络与代理设置

### 操作步骤：配置网络代理

1. 打开设置 → 点击左侧「网络」标签
2. 开启代理开关
3. 配置代理信息：
   - **代理类型**：HTTP 或 SOCKS5
   - **代理地址和端口**
   - **认证信息**（可选）：用户名和密码
   - **代理绕过列表**：配置不走代理的域名
4. 还可以配置：
   - **自定义 Claude Code 路径**：手动指定 Claude 命令位置
   - **Git Bash 路径**（Windows）：指定 Git Bash 安装位置

## 数据管理

### 操作步骤：导出对话数据

1. 打开设置 → 点击左侧「数据」标签
2. 找到「导出」区域
3. 选择导出范围：全部数据 / 当前工作区
4. 选择导出格式：JSON 或 Excel
5. 点击导出按钮，选择保存位置
6. 等待导出完成

### 操作步骤：导入对话数据

1. 打开设置 → 点击左侧「数据」标签
2. 找到「导入」区域
3. 选择之前导出的备份文件
4. 等待导入完成，冲突数据会自动处理

### 操作步骤：设置自动备份

1. 打开设置 → 点击左侧「数据」标签
2. 找到「数据库备份」区域
3. 设置「备份目录」：点击选择备份文件存放位置
4. 设置「备份频率」：
   - 手动：仅在你手动触发时备份
   - 每天：每日自动备份一次
   - 每周：每周自动备份一次
5. 系统自动保留最近备份，旧备份自动清理

### 操作步骤：清理存储空间

1. 打开设置 → 点击左侧「数据」标签
2. 查看数据库大小和对话统计
3. 选择清理范围：3 个月前 / 6 个月前 / 全部
4. 确认后清理旧数据

### 数据安全说明
- 所有对话数据存储在本地 SQLite 数据库
- 不上传用户对话内容到服务器
- 支持完全离线使用（配合本地模型）

## 语音模型设置

### 操作步骤：下载和配置语音识别模型

1. 打开设置 → 点击左侧「语音模型」标签
2. 页面显示可用的语音识别模型
3. 如果模型未下载，点击「下载」按钮
4. 等待模型下载完成（模型在本地运行，保障隐私）
5. 下载完成后自动启用
6. 可查看语音识别历史记录

## 账户

### 操作步骤：查看账户信息

1. 打开设置 → 点击左侧「账号」标签
2. 显示当前用户信息：头像、昵称、邮箱、手机号、用户名

### 操作步骤：退出登录

1. 打开设置 → 点击左侧「账号」标签
2. 点击「退出登录」按钮
3. 退出后进入游客模式

### 游客模式说明
- 无需登录即可使用大部分功能
- 以下功能受限：
  - 不可查看反馈历史
  - 不可发布技能到雇佣牛马
