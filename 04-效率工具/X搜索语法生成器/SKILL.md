# X搜索语法生成器

根据用户的自然语言描述，自动生成X平台的高级搜索语法。

---

## 使用流程

1. 用户用自然语言描述想搜索的内容
2. 分析需求，提取关键要素（关键词、语言、时间、互动数、内容类型）
3. 生成对应的X搜索语法
4. 提供使用说明和调整建议

---

## 核心要素识别

从用户描述中提取以下要素：

### 1. 关键词
- 识别核心主题词（如"AI"、"比特币"、"留学"）
- 识别相关词（如"ChatGPT"、"大模型"、"提示词"）
- 用 `"词1" OR "词2" OR "词3"` 格式组合

### 2. 语言
- 中文 → `lang:zh-cn`
- 英文 → `lang:en`
- 日文 → `lang:ja`
- 未指定 → 不添加语言限制

### 3. 时间范围
- "最近X小时" → `within_time:Xh`
- "最近X天" → `within_time:24h`（X平台最多支持24h）
- "实时/正在发生" → `within_time:1h`
- 未指定 → 不添加时间限制

### 4. 互动门槛
- "爆款/万赞" → `min_faves:10000`
- "高质量/热门" → `min_faves:1000-5000`（根据语言调整）
- "中等热度" → `min_faves:300-500`
- "小众/精准" → `min_faves:100`
- 未指定 → 根据语言设置默认值（英文5000，中文500）

### 5. 内容类型
- "视频" → `filter:native_video`
- "图片/带图" → `filter:images`
- "原创/排除转发" → `-is:retweet`
- "排除回复" → `-filter:replies`
- "排除链接" → `-filter:links`

---

## 语言默认值

不同语言的内容活跃度不同，需要调整默认互动门槛：

- **英文** (`lang:en`)：默认 `min_faves:5000`（内容量大）
- **中文** (`lang:zh-cn`)：默认 `min_faves:500`（内容量中等）
- **日文** (`lang:ja`)：默认 `min_faves:1000`（内容量中等）

**用户输入**：
"我想找AI领域12小时内点赞超5000的英文内容"

**生成语法**：
```
("AI" OR "ChatGPT" OR "Claude" OR "GPT") lang:en min_faves:5000 within_time:12h
```

**使用说明**：
1. 复制上方搜索语法到X搜索框

**调整建议**：

- 想要更精准 → 添加更多关键词：`("AI" OR "ChatGPT") ("product" OR "launch")`

## 注意事项

1. **关键词组合**：用 `OR` 连接相关词，提高召回率
2. **语言识别**：根据用户描述自动判断语言，未明确时不添加语言限制
3. **时间限制**：X平台最多支持 `within_time:24h`，超过24小时不添加时间限制
4. **互动门槛**：根据语言和需求自动调整，避免结果过少或过多
5. **过滤器组合**：可以组合多个过滤器，如 `-is:retweet -filter:replies`
6. **调整建议**：必须提供具体的调整方案，不要只说"调整参数"

## 高级技巧

### 组合搜索
```
("关键词1" OR "关键词2") ("限定词1" OR "限定词2") lang:en min_faves:1000
```

### 排除特定词
```
"AI" -"广告" -"推广" lang:zh-cn min_faves:500
```

### 精准匹配
```
"exact phrase" lang:en min_faves:1000
```

### 多条件过滤
```
"AI" lang:en min_faves:5000 filter:images -is:retweet -filter:links
```
