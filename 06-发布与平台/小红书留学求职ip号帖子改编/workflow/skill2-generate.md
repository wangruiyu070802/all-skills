# Skill 2：生成产出

**触发词**：`生成产出` / `写一篇素人文`

---

## 执行步骤

### 1. 读取最新版 prompt

在 `1_prompts/` 文件夹中找到版本号最高的 prompt 文件，读取内容。

### 2. 询问用户选择人设

列出 `0_personas/` 中的所有人设，让用户选择本次使用哪个人设。

### 3. 询问用户提供参考文章

请用户粘贴一篇参考文章（作为风格和内容框架的模板）。

### 4. 换皮仿写

基于 prompt 的写作规范，将参考文章中的人设相关部分（身份、经历、数字、细节等）替换为指定人设的信息，生成新文章。

**保留参考文章的：**
- 整体结构和段落逻辑
- 语言风格和口吻
- 核心观点和方法论
- 情绪节奏和转折

### 5. 保存产出

将产出保存为 `2_outputs/v{n}_output_01.md`（扁平化命名，如已存在则递增编号）。

### 6. 创建反馈模板

创建或更新 `3_feedback/v{n}_feedback.md`（反馈文件只写引用路径，不复制产出全文）：

使用 [反馈模板](../templates/feedback-template.md)

### 7. 向用户报告

"产出已生成。请在 `3_feedback/v{n}_feedback.md` 中填写您的反馈。完成后请说「开始迭代」。"
