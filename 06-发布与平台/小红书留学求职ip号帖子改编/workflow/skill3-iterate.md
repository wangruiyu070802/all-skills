# Skill 3：开始迭代

**触发词**：`开始迭代` / `根据反馈迭代`

---

## 第一阶段：评估

### 1. 确定当前版本号

确定当前最新版本号 `n`。

### 2. 通读所有材料

- `1_prompts/v{n}.md`（当前版本 Prompt）
- `2_outputs/v{n}_output_*.md`（当前版本所有产出）
- `3_feedback/v{n}_feedback.md`（当前版本反馈）
- `golden_rules.md`（所有历史规则）

### 3. 综合评判

**"基于目前的信息，现在进行迭代，是否能有效推进项目？"**

评估：
- 反馈是否足够清晰、具体、可操作？
- 是否存在反馈之间的矛盾或与 golden_rules 的冲突？
- 是否需要更多产出样本来验证？

### 4. 给出判断

- **如果可以迭代**：说明理由，询问"是否确认执行迭代？"
- **如果建议暂缓**：说明顾虑，给出具体建议。

---

## 第二阶段：执行（需用户确认后）

### 5. 学习与提炼

从反馈中识别具有普适性的规则，追加到 `golden_rules.md`。

### 6. 重构 Prompt

创建 `1_prompts/v{n+1}.md`，以旧版为基础进行外科手术式修改。

### 7. 生成新版产出

基于新版 prompt 生成一篇素人文，保存到 `2_outputs/v{n+1}_output_01.md`。

### 8. 生成反馈模板

创建 `3_feedback/v{n+1}_feedback.md`。

### 9. 交付

向用户报告迭代结果，提示填写新版反馈。
