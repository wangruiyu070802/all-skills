# 元 Claude Skill —— Prompt 迭代工程生成器

## 这是什么？

这是一个「元工具」。你只需要用自然语言描述一个内容创作场景，它就能自动生成一套完整的 **Prompt 迭代工程项目**（包含 CLAUDE.md、初始 Prompt、文件夹结构）。

就像「元 Prompt」帮你把乱七八糟的话变成 Prompt 一样，「元 Claude Skill」帮你把模糊的场景描述变成一套可运行的迭代工程。

---

## Skills

### Skill 1：生成新项目

- **触发词**：`生成项目` / `新建场景` / `创建迭代工程`
- **动作**：

    **第一步：收集信息**

    询问用户以下问题（可以一次性回答，也可以对话式补充）：

    1. **场景名称**：这个项目叫什么？（如：公众号转口播稿、知乎回答、朋友圈文案）
    2. **输入是什么**：智能体接收什么作为输入？（如：一篇公众号文章、一个话题、一段素材）
    3. **输出是什么**：智能体要产出什么？（如：视频号口播稿、知乎风格回答、朋友圈文案）
    4. **核心转换逻辑**：从输入到输出，最关键的转换规则是什么？（如：去书面语、加口语化、控制在60秒内）
    5. **是否需要人设**：这个场景需要人设库吗？（如：需要/不需要）
    6. **质量标准**：什么样的产出算「好」？（如：读起来自然、有节奏感、能引发互动）

    **第二步：生成项目**

    基于用户的回答，在指定路径下创建完整的项目结构：

    ```
    {项目名称}/
    ├── CLAUDE.md          # 项目说明书（自动生成，包含定制化的 Skills）
    ├── 0_personas/        # 人设库（如果需要）
    ├── 1_prompts/
    │   └── v1.md          # 初始版 System Prompt（自动生成）
    ├── 2_outputs/         # 产出文件夹
    ├── 3_feedback/        # 反馈文件夹
    └── golden_rules.md    # 黄金法则（初始为空或包含基础规则）
    ```

    **第三步：交付**

    向用户报告：
    - 项目已创建在 `{路径}`
    - 简要说明如何使用（触发词列表）
    - 建议的下一步操作

### Skill 3：场景灵感

- **触发词**：`场景灵感` / `有哪些场景`
- **动作**：列出常见的可迭代内容创作场景，帮助用户找到灵感：

    | 场景 | 输入 | 输出 | 是否需要人设 |
    |:---|:---|:---|:---|
    | 小红书素人文 | 参考文章 + 人设 | 换皮仿写文章 | ✅ |
    | 公众号转口播稿 | 公众号文章 | 60秒视频口播稿 | ❌ |
    | 知乎回答 | 问题 + 素材 | 知乎风格回答 | ✅ |
    | 朋友圈文案 | 产品/事件 | 朋友圈文案 | ❌ |
    | Twitter/X 线程 | 长文/观点 | 推特线程 | ❌ |
    | 播客大纲 | 话题 | 播客对话大纲 | ✅ |
    | 邮件润色 | 草稿邮件 | 正式邮件 | ❌ |
    | 产品文案 | 产品信息 | 营销文案 | ❌ |

## CLAUDE.md 生成模板

当生成新项目时，CLAUDE.md 应包含以下结构（根据场景定制内容）：

```markdown
# 项目：{场景名称}智能体迭代工程

## 1. 项目目标

通过人机协作，持续迭代优化一个能{核心能力描述}的智能体 System Prompt。

## 2. 文件夹结构约定

| 路径 | 用途 |
|:---|:---|
| `CLAUDE.md` | 项目说明书 |
| `0_personas/` | 人设库（如适用） |
| `1_prompts/v{n}.md` | 第 n 版 System Prompt |
| `2_outputs/v{n}_output_xx.md` | 第 n 版产出 |
| `3_feedback/v{n}_feedback.md` | 第 n 版反馈 |
| `golden_rules.md` | 黄金法则 |

## 3. Skills

### Skill 1：初始化项目
[根据场景定制]

### Skill 2：生成产出
[根据场景定制 - 这是最关键的部分，需要描述具体的生成流程]

### Skill 3：开始迭代
[标准迭代流程，可复用]

### Skill 4：查看状态
[标准状态查看，可复用]

### Skill 5+：场景特有 Skills
[根据场景需要添加，如：添加人设、添加范例等]

## 4. 工作流循环

[标准循环图]

## 5. 重要约束

[标准约束 + 场景特有约束]
```

## v1.md 生成模板

初始版 System Prompt 应包含：

```markdown
# {场景名称} System Prompt V1

## 你的角色
你是一个专业的{角色描述}。

## 输入
你会收到：{输入描述}

## 输出要求
你需要产出：{输出描述}

## 核心规则
{根据用户描述的转换逻辑生成 3-5 条核心规则}

## 格式要求
{输出格式规范}

## 好范例
（待补充）

## 差范例
（待补充）
```

---

## 重要约束

- 生成的项目必须是**自包含**的，用户拿到后可以直接在新文件夹中使用。
- CLAUDE.md 中的 Skills 必须**具体可执行**，不能是抽象描述。
- 初始 v1.md 要有**实际内容**，不能全是占位符。
- 根据场景智能判断是否需要人设库、范例库等可选模块。
