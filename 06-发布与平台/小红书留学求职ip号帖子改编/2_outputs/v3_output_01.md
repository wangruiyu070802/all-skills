# 改编文章

我真觉得1月是北美找工最好的时间

之前从Amazon跳去做量化之后，为了帮助transition，最近也参与了一些组内的招聘流程。算是从求职者转换成面试者的视角，重新观察找工这件事，其实有3个关键点

1️⃣ 时间
1-4月招聘季，新一年budget刚刚开放，好多岗位都会出来，抓好这个时间，hiring manager也求贤若渴。建议投递完直接linkedin dm这个岗位的hiring manager，只要你的linkedin展示面好的话，基本上都会愿意和你聊的

2️⃣找做决策的人
去network100个公司里面的人，不如直接聊1个岗位的manager或者director。有些组的senior权利也很大，所以找到"做决策的人" 很重要

3️⃣高能量
面试的时候，明显会看到有些candidate能量很低，说什么答什么。但是有些candidate就是能量很高，把本来枯燥无味面试变成了一种有来有回的coffeechat，这个感觉对于面试官来讲也是很舒服的，会留下深刻印象，考虑offer的时候确实会有倾向性

第二波比较大的招聘季就是9到11月，这一波也要好好抓紧，基本上是因为公司员工跳槽需要去填坑（我当时从Amazon跳出来就是这样的😂）

那应该怎么利用好这个现象呢

12月-1月中准备面试相关的材料
1月-4月集中networking+每天30-50份投递岗位
5-8月可以多去线下networking活动+side project
9-11月继续集中networking+投递岗位

🎯核心逻辑：把握1-4月黄金期

很多人问我怎么学会这些的：说实话22年秋招那会儿，我也是到处搜集信息，找学长学姐请教，一路摸爬滚打过来的。后来拿了5个offer包括Amazon和Google，踩过的坑、学到的东西，现在都在教给学弟学妹

最后祝5月毕业的宝宝们可以提前拿到offer～
