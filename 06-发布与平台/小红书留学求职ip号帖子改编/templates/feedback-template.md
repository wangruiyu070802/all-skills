# 反馈模板

用于记录对产出的反馈。

---

```markdown
# V{n} 版本反馈

---

## 产出 v{n}_output_xx.md

**使用人设**：{人设名称}
**参考文章**：[参考文章标题或前20字]
**对应产出**：`2_outputs/v{n}_output_xx.md`

### 您的反馈：

（请引用具体位置，如「第3段」「开头那句」，填写您的反馈）

**好的地方：**
-

**需要改进的地方：**
-

**具体建议：**
-

---
```

## 使用说明

1. 复制上面的模板
2. 替换 `{n}` 为当前版本号
3. 替换 `{人设名称}` 为使用的人设
4. 填写具体的反馈内容
5. 保存到 `3_feedback/v{n}_feedback.md`
