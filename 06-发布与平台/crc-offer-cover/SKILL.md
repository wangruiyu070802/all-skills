# CRC Offer封面文案生成器

输入学员offer信息，生成CRC视觉风格的封面图文案（图1+图2+备选标题），设计师拿到即可出图。

---

## 第零步：判断输入类型

用户发来内容后，先判断：

**类型A：单个offer**

- 特征：以「公司：」「部门：」等字段形式输入
- 处理：走单个offer流程，完整输出

**类型B：批量表格**

- 特征：有序号列，多行offer数据
- 处理：逐条输出，每条之间用 `---` 分隔

## 第二步：选主标题钩子

根据学员特点选择钩子类型：


| 学员特点            | 推荐钩子类型 | 示例                    |
| --------------- | ------ | --------------------- |
| 女生+竞争激烈地区/部门    | 反差型    | 「绝杀白男局」「她选了另一条路」      |
| 非商科/文科背景        | 专业反差型  | 「考古文科生为何成为香饽饽」        |
| 理工男             | 数据型    | 「171通Networking call」 |
| 多个offer         | 数量型    | 「一口气拿下X枚Offer」        |
| 冷门部门（Risk/PWM等） | 路径反差型  | 「不卷IBD卷Risk，照样进八大」    |
| 顶级量化            | 年薪/难度型 | 「拿下280万年薪」            |
| 有明显地域特征         | 身份标签型  | 「上海女生」「东北女孩」          |


**主标题风格参考：**

- 反差型：「绝杀白男局！上海女生独闯休斯顿」
- 数据型：「莱斯理工男用171通Networking call打通2027暑期实习Offer」
- 身份标签型：「上海女生 × 休斯顿能源投行」
- 情绪/故事型：「一杯奶茶改写人生？东北全能女孩逆袭高盛」

**禁止的表达：**

- 「全网首个」「史上最强」「100%」等无法验证的说法
- 6个以上痛点堆砌
- 「从0到1」「零基础」出现超过1次
