# V2 投流帖改编规则

## 改编原则

**核心原则**：能不改就不改，只改必须改的。

## 必须改的内容

1. **品牌名**：竞品名称 → 橙然/橙然CRC
2. **数据**：竞品数据 → 橙然数据（400+企业、99%成功率等）
3. **企业名称**：替换为橙然合作企业清单中的企业
4. **钩子**：改为自然的引流方式（见下方详细规则）
5. **标签**：删除竞品标签，添加橙然相关标签

## 引流钩子规则（V2更新）

**禁止**：
- 「评论区扣【xxx】，我发你xxx」
- 「私信我领取xxx」
- 任何像销售话术的表达

**推荐模板**：
- 「如果你是美本/英本大一大二的同学，对金融/咨询/科技有兴趣，欢迎随时📩小编！」
- 「有问题欢迎随时📩小编聊聊～」
- 根据内容主题灵活调整目标人群描述

**原则**：引流钩子要像朋友推荐，不像销售话术

## 结尾规则（V2更新）

**禁止**：
- 所有帖子都加「2026加油，都能上岸！💪」
- 强行加口号式结尾

**推荐**：
- 根据内容灵活处理
- 可以保留原帖结尾风格
- 或直接以引流钩子收尾，不加额外结尾语

**原则**：自然收尾，不要千篇一律

## 保持不变的内容

1. **原帖的结构和逻辑**
2. **通用的干货内容和方法论**
3. **岗位名称、行业通用术语**

## 改编流程

1. 接收竞品投流帖的图片和文案原文
2. 逐张识别图片中的所有文字
3. 分析原帖结构
4. 识别需要替换的元素
5. 改编文案
6. 改编图片：逐张图片、逐个文字元素对比，标注「✅ 不改」或「❌ 需要改」
7. 输出完整方案：
   - 一、设计师改动清单（按图片逐张输出）
   - 二、文案（直接复制）

## 输出格式

### 一、设计师改动清单

按图片逐张输出，只列出需要改动的内容。整张图不用改则标注「✅ 不用改，直接用」。

```
【图1】 ✅ 不用改，直接用
【图2】 ❌ 需改动
位置原文 → 改为xxxxxxxxx
【图3】...
```

### 二、文案（直接复制）

```
标题：xxx
正文：
（完整改编后的文案）
标签：#xxx #xxx
```
