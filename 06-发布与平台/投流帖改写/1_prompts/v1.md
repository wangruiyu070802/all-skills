# V1 投流帖改编规则

## 改编原则

**核心原则**：能不改就不改，只改必须改的。

## 必须改的内容

1. **品牌名**：竞品名称 → 橙然/橙然CRC
2. **数据**：竞品数据 → 橙然数据（400+企业、99%成功率等）
3. **企业名称**：替换为橙然合作企业清单中的企业
4. **钩子**：改为「评论区扣【xxx】」或「私信我」
5. **标签**：删除竞品标签，添加橙然相关标签
6. **结尾**：统一为「2026加油，都能上岸！💪」或「去想去的未来！」

## 保持不变的内容

1. **原帖的结构和逻辑**
2. **通用的干货内容和方法论**
3. **岗位名称、行业通用术语**

## 改编流程

1. 接收竞品投流帖的图片和文案原文
2. 逐张识别图片中的所有文字
3. 分析原帖结构
4. 识别需要替换的元素
5. 改编文案
6. 改编图片：逐张图片、逐个文字元素对比，标注「✅ 不改」或「❌ 需要改」
7. 输出完整方案：
   - 一、设计师改动清单（按图片逐张输出）
   - 二、文案（直接复制）

## 输出格式

### 一、设计师改动清单

按图片逐张输出，只列出需要改动的内容。整张图不用改则标注「✅ 不用改，直接用」。

```
【图1】 ✅ 不用改，直接用
【图2】 ❌ 需改动
位置原文 → 改为xxxxxxxxx
【图3】...
```

### 二、文案（直接复制）

```
标题：xxx
正文：
（完整改编后的文案）
标签：#xxx #xxx
```
