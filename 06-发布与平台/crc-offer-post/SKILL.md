# CRC学员Offer小红书帖子生成器

输入学员offer信息，一站式输出：Offer审查 → 封面文案（图1+图2）→ 小红书正文 → 标签 → 备选主标题。

---

## 工作流程

```
收到offer信息/截图
      ↓
【第一步】提取关键信息 + 自动推断缺失字段
      ↓
【第二步】Offer审查（读取 references/offer-audit.md）
      ↓
  发现问题 → 输出审查报告，暂停，等用户确认
  无问题   → 继续
      ↓
【第三步】生成封面文案（图1+图2+备选标题）
      ↓
【第四步】生成小红书正文（读取 references/post-writing-guide.md）
      ↓
【第五步】生成标签
      ↓
输出完整内容
```

---

## 输入方式

### 方式1：文字信息

```

背景故事：[可选，如有特殊经历请补充]
```

### 方式2：Offer截图

直接发送截图，自动提取信息。

### 方式3：批量表格

多行offer数据，逐条处理，每条之间用 `---` 分隔。

## 第一步：信息推断

收到offer信息后，自动推断缺失字段。推断规则见 `references/company-data.md`，包含：
- 公司定位词（八大投行/Tier1精品投行/顶级对冲基金...）
- 届别推断（根据实习类型推算年级）
- 专业推断（根据部门推荐专业组合）

---

## 第二步：Offer审查

生成内容前，先完成审查。详细审查清单见 `references/offer-audit.md`。

审查通过时输出：

```

| 字段 | 内容 |
|-----|------|
| 公司 | [确认] |
| 部门 | [确认] |
| 地点 | [确认] |
| 实习类型 | [确认] |
| 时间线 | [确认] |

未发现逻辑漏洞，开始生成内容👇
```

审查发现问题时输出审查报告，暂停等用户确认后再继续。

## 第四步：生成小红书正文

正文采用6段式结构，详细写法指南见 `references/post-writing-guide.md`：

```
1. 【开头钩子】画面感/反差/悬念 + Offer前置展示🔥（2-3句）
      ↓
2. 【差异化背景】具体的时间点、事件、细节（2-3句）
      ↓
3. 【困境/转折】迷茫、焦虑、信息缺失⚠️（2-3句）
      ↓
4. 【加入CRC + CRC作用】有仪式感的时刻✅ + 具体帮助（4-6句）
      ↓
5. 【高潮考验 + 结果】面试紧张感‼️ + 金句 + offer落地🎉（4-6句）
      ↓
6. 【总结归因 + CTA】不是运气是XX + 欢迎DM（2-3句）
```

### 正文核心规则

- **Offer前置**：开头必须展示offer结果，用🔥emoji列出
- **CRC加入要有仪式感**：不能只写「于是她加入了CRC」，要有时间/场景/触发事件
- **CRC作用要具体**：不能写「系统性准备面试」，要写具体做了什么（搭框架、写memo、脱稿练逻辑）
- **高潮要有紧张感**：面试细节、突发状况、时间压力
- **短句 + 空行分隔**：节奏快，不写大段落

### emoji使用

每1-2段至少1个emoji，不过度堆砌。常用：🔥（offer展示）、👉（引导）、👇（承接）、⚠️（困境）、✅（转折）、‼️（高潮）、🎉（结果）

## 禁止的表达

- 「全网首个」「史上最强」「100%」等无法验证的说法
- 6个以上痛点堆砌
- 「从0到1」「零基础」出现超过1次
- AI味：排比对仗、学术词、金句式收尾
